# 운용자(작업자) 가이드 - 조준경 불량 검사 프로그램

프로그램을 실행해서 조준경 한 개를 검사하고 종료할 때까지, 실제 화면에서 무엇을 누르고
무엇을 확인해야 하는지 순서대로 정리한 문서입니다. 설치/개발 관련 내용은
`docs/windows_setup_guide.md`를 참고하세요 - 이 문서는 "이미 설치되어 실행 가능한 상태"를
전제로 합니다.

## 1. 프로그램 실행

바탕화면 아이콘(`ScopeInspector.exe`) 또는 아래 명령으로 실행합니다.

```
ScopeInspector.exe
```

- 실행하면 프로그램 창이 작업표시줄을 제외한 화면 전체 크기로 자동으로 커집니다.
- 카메라가 연결되어 있지 않거나 인식에 실패하면 콘솔/로그에 오류가 남습니다 - 이 경우
  IDS peak Cockpit 프로그램으로 카메라가 먼저 정상 인식되는지 확인하세요.

## 2. 화면 구성

| 위치 | 내용 |
|---|---|
| 좌측(화면 대부분) | 카메라 실시간 영상 - 항상 떠 있으며, 어느 탭에 있든 계속 보입니다 |
| 우측 상단 탭 | **시험 진행** / **캘리브레이션** / **카메라 설정** / (DB 연결 시) **결과 조회** |

평소 검사 작업은 거의 항상 **"시험 진행"** 탭에서만 이루어집니다. 캘리브레이션/카메라 설정은
장비를 처음 설치하거나 카메라를 교체했을 때만 손댈 일이 있습니다.

영상 하단에는 확대 슬라이더 외에 **오버레이 표시** 체크박스 4개(원점/기준선, 레드닷,
안내선(노란선), 오차 정보(R/U))가 있어, 화면에 정보가 너무 많다고 느껴지면 필요 없는
항목만 개별로 꺼둘 수 있습니다. **전체 보이기/전체 숨기기** 버튼으로 한 번에 모두
켜거나 끌 수도 있습니다. (이 컨트롤들은 "시험 진행" 탭 맨 위에 있습니다.)

## 3. (최초 1회 또는 카메라 교체 시) 캘리브레이션

이미 이 장비에서 캘리브레이션을 저장해둔 적이 있다면 **프로그램 시작 시 자동으로 불러와지므로**
이 단계는 건너뛰어도 됩니다. "캘리브레이션" 탭 상태 메시지가 "불러오기 완료."면 정상이고,
"스케일이 미확정"이라고 뜨면 4번부터 다시 진행해야 합니다. (수동으로 다시 불러오고 싶으면
**불러오기** 버튼을 눌러도 됩니다.)

새로 캘리브레이션해야 한다면:

1. 우측 탭에서 **"캘리브레이션"**을 클릭합니다 - 이때 좌측 영상이 확대/크롭 없이
   원본 그대로 표시되는 모드로 바뀝니다(그리드 눈금 전체를 보기 위함).
2. **"그리드 자동 검출"** 버튼을 눌러 원점(중심 십자선)을 자동으로 잡습니다. 성공하면
   상태 메시지에 원점 좌표가 표시되고, 영상에 하늘색 십자 마커와 빨간 좌표축이 나타납니다.
   실패하면(조명이 어둡거나 십자선을 못 찾으면) **"그리드 수동 검출 (영상 클릭으로 원점
   지정)"**을 누른 뒤 영상에서 원점(중심 십자선)으로 보이는 위치를 직접 클릭하세요.
3. 이 시점의 빨간 좌표축은 아직 대략적인 추정치라 실제 그리드와 안 맞을 수 있습니다 -
   **원점 미세조정** 화살표(0.5px 단위)로 하늘색 십자 마커를 실제 중심에 맞추고,
   **눈금 간격(px/MOA) 미세조정**(큰 폭/미세 버튼, X/Y 각각)으로 빨간 좌표축의 눈금
   간격이 실제 그리드와 겹치도록 조정합니다. 원점 부근만 맞고 먼 지점(±35MOA 근처)에서
   벌어져 보이면 눈금 간격이 아직 덜 맞은 것이니 계속 조정하세요.
4. 다 맞았으면 **"저장"**을 누릅니다 - 이후 이 카메라에서는 프로그램을 껐다 켜도
   "불러오기"로 바로 이 값을 다시 쓸 수 있습니다.
5. 다시 우측 탭에서 **"시험 진행"**을 눌러 원래 화면(확대/크롭 적용)으로 돌아갑니다. 만약
   눈금 간격을 X/Y 중 한쪽만 조정했다면(둘 다 조정해야 확정됩니다) "시험 진행" 탭 상단에
   빨간 경고("스케일 미확정")가 뜨니 참고하세요.

## 4. (선택) 카메라 설정 확인

"카메라 설정" 탭에서 노출 시간, 게인, 화이트밸런스 등 세부 항목을 확인/조정할 수 있습니다.
현장 표준값이 기본으로 이미 채워져 있으므로, 특별한 문제가 없으면 건드릴 필요가 없습니다.
값을 실수로 바꿨다면 **"기본값 복원"**을 누르면 즉시 표준값으로 되돌아갑니다. 값을 바꾼
뒤에는 **"적용 (카메라에 반영)"**을 눌러야 실제 카메라에 반영됩니다.

## 5. 검사 시작 - 부품 ID 입력

"시험 진행" 탭 맨 위의 **부품 ID** 입력란에 검사할 조준경의 ID를 입력합니다.

- **부품 ID를 입력하지 않으면 검사를 시작할 수 없습니다** (2단계 시작 버튼을 눌러도
  "부품 ID를 먼저 입력하세요" 메시지가 뜨고 진행되지 않습니다).
- 이전 부품과 다른 조준경으로 바꿀 때는 이 칸의 값을 새 ID로 바꿔주면 됩니다.

## 6. 1단계 - 렌즈 정렬

1. 조준경 연결 장비를 조작해 레드닷을 그리드 **중앙(0,0)**으로 이동시킵니다.
2. 화면의 "오차: x=..., y=..., 거리=..." 표시를 보면서 오차를 줄여갑니다.
3. 오차가 허용 범위 이내로 들어가 잠깐 안정되면(흔들리지 않으면) 자동으로
   **"정렬 완료 - 2단계 준비됨"**으로 바뀝니다. 버튼을 따로 누를 필요는 없습니다.

## 7. 2단계 - 트래블 검사 (상/하/좌/우)

방향마다 독립된 박스(상/하/좌/우)가 있고, 각 박스에는 **시작(재시작)** 버튼과
**데드클릭** 버튼만 있습니다. 순서는 자유입니다 - 아무 방향이나 먼저 눌러도 되고, 실패한
방향만 다시 눌러도 됩니다.

### 7-1. 한 방향 시험 진행 방법

1. 검사할 방향의 **"시작"** 버튼을 누릅니다. (다른 방향이 진행 중이었다면 그 미완성
   기록은 자동으로 폐기되고 새로 누른 방향이 시작됩니다 - 동시에 두 방향을 진행할 수
   없기 때문입니다.)
2. 조절나사를 돌려 레드닷을 그 방향으로 목표(약 35MOA)까지 이동시킵니다.
3. 목표 근처에서 **눈금을 확인하려고 잠깐 멈추기만 하면** 이동량/쉬프트/드리프트가
   자동으로 평가됩니다 - 버튼을 누를 필요가 없습니다.
   - 만약 기계적 한계로 35MOA에 도달하지 못하고 그 전에 더 이상 안 돌아간다면, 그 상태로
     멈춰도 자동 평가가 되지 않습니다(아직 목표 근처가 아니라고 판단하기 때문). 이 경우
     지금 이 위치가 최대 이동 지점임을 프로그램에 알려줘야 하며, 화면에 안내가 뜹니다.
4. 위 3개 검사(이동량/쉬프트/드리프트) 중 하나라도 불량이면 그 즉시 이 방향 시험이
   종료됩니다(박스 상태가 "불량"으로 바뀜).
5. 모두 통과했다면 자동으로 **복귀 단계**로 넘어갑니다 - "원점으로 복귀 중" 안내가
   뜨면 레드닷을 다시 원점(0) 쪽으로 되돌립니다.
6. 원점 근처에서 잠깐 멈추면 **백래쉬**가 자동으로 평가되고 이 방향 시험이 종료됩니다
   (박스 상태가 "합격" 또는 "불량"으로 바뀜, 시작 버튼도 "재시작"으로 바뀝니다).

### 7-2. 데드클릭 처리

클릭해도 레드닷이 거의 움직이지 않는 경우(데드클릭)는 프로그램이 자동으로 판단하지
않습니다 - 그 방향 박스의 **"데드클릭"** 버튼을 직접 눌러 알려줘야 하며, 누르는 즉시
그 방향은 불량으로 즉시 종료됩니다. (다른 검사 중이 아니라 그 방향 시작 후 언제든
누를 수 있습니다.)

### 7-3. 도중에 멈춰야 할 때 - 시험 중지 / 전체 재시작

- **시험 중지**: 검사 도중 "이건 별도 교정이 필요하다" 싶으면 언제든 누릅니다. 지금까지의
  진행 데이터는 **저장되지 않고 완전히 폐기**됩니다(불량으로도 기록되지 않음). 이후 교정
  등 조치를 하고 나서 같은 방향의 "시작(재시작)" 버튼을 다시 누르면 처음부터 재진행됩니다.
- **전체 재시작**: 지금까지의 모든 방향 기록을 전부 지우고 이 부품의 검사를 처음부터
  다시 시작합니다.

### 7-4. 종합 결과 표 읽는 법

화면 중앙의 표는 항목(이동량/데드클릭/드리프트/쉬프트/백래쉬) x 방향(상/하/좌/우)로
구성되어 있고, 맨 오른쪽 "결과" 열에 그 항목의 4방향 종합 판정(합격/불량)이 표시됩니다.

- `-` : 아직 그 방향이 시작되지 않았거나, 그 항목까지 도달하지 못함(앞 항목에서 이미
  불량으로 종료됨)
- 빨간 글씨 : 불량
- 검은 글씨 숫자 : 실측값(MOA 단위, 데드클릭은 "발생"/"X"로 표시)

### 7-5. 검사 종료 - 시험 종료(결과 저장)

4방향 모두 한 번씩 완료되면(합격/불량 무관) 화면 하단의 **"시험 종료 (결과 저장)"**
버튼이 활성화됩니다. 이 버튼을 눌러야 실제로 DB에 결과가 저장됩니다 - 누르기 전까지는
저장되지 않으므로, 결과가 이상해 보이면 저장 전에 문제 방향만 "재시작"으로 다시 진행할
수 있습니다. **한 번 "시험 종료"를 누르면 이 부품에 대해서는 더 이상 재시험할 수
없습니다** - 새 조준경을 검사하려면 부품 ID를 바꾸고 새로 시작하세요.

## 8. 결과 조회 (DB 연결된 경우)

"결과 조회" 탭에서 부품 ID로 과거 검사 이력을 조회할 수 있습니다.

1. 조회할 부품 ID를 입력하고 **"조회"**를 누릅니다.
2. 표에 그 부품의 검사 세션 이력(시작/종료 시각, 최종 판정 등)이 표시됩니다.
3. **"CSV 내보내기"**로 조회된 결과를 파일로 저장할 수 있습니다.

## 9. 프로그램 종료

창을 그냥 닫으면(오른쪽 위 X 버튼) 카메라 연결이 정리되고 프로그램이 종료됩니다.
**저장은 "시험 종료" 버튼을 누른 시점에 이미 완료된 상태**이므로, 창을 닫기 전에
진행 중이던 검사가 있다면 먼저 "시험 종료"를 눌러 저장했는지 확인하세요(저장 전에 창을
닫으면 그 부품의 결과는 저장되지 않습니다).

## 10. 자주 발생하는 상황

| 상황 | 해야 할 일 |
|---|---|
| "부품 ID를 먼저 입력하세요" 메시지가 뜸 | 상단 부품 ID 칸을 비워둔 상태 - ID를 입력 |
| 목표(35MOA)까지 이동했는데 자동 평가가 안 됨 | 잠깐(1초 이상) 완전히 멈춰야 인식됩니다 - 손을 떼고 잠시 기다려보세요 |
| 기계적 한계로 35MOA까지 못 감 | 그 지점에서 화면 안내에 따라 수동으로 "여기까지가 한계"임을 확정 |
| 단독 클릭 한 번에 레드닷이 거의 안 움직임 | 자동 감지 대상이 아님 - 데드클릭 버튼을 직접 누르세요 |
| 잘못 눌러서 엉뚱한 방향이 시작됨 | 그 방향에서 "시험 중지"를 누르면 미기록으로 폐기되고, 원하는 방향을 다시 시작 |
| 레드닷 오차 표시가 눈금과 안 맞아 보임 | "캘리브레이션" 탭에서 재검출/미세조정 필요 - 3번 항목 참고 |
| 카메라 화면이 안 나옴 | IDS peak Cockpit에서 카메라가 먼저 인식되는지 확인 (드라이버/USB 문제) |
| "시험 종료"를 눌렀는데 다시 고치고 싶음 | 이미 저장 후에는 재시험 불가 - 같은 부품이면 새 세션으로 다시 검사해야 함(운영 정책에 따라 담당자와 상의) |
